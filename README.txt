BÀI TẬP RESPONSIVE WEB DESIGN

Tệp trong dự án:
- index.html: cấu trúc trang web, nội dung và ảnh có văn bản thay thế (alt).
- style.css: giao diện mobile-first và các media query.

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục responsive_design_assignment.
3. Nhấp đúp index.html để mở bằng trình duyệt.
4. Để kiểm tra responsive, nhấn F12 trong Chrome rồi bật chế độ thiết bị (Device Toolbar).
5. Kiểm tra các kích thước nhỏ hơn 772px, từ 772px và từ 992px.

Các điểm chính:
- Mặc định một cột cho màn hình nhỏ.
- Từ 772px: bố cục hai cột.
- Từ 992px: bố cục ba cột.
- Ảnh có alt mô tả.
- Có hỗ trợ prefers-reduced-motion.
- Ảnh dùng URL Unsplash nên cần kết nối Internet để hiển thị.

Lưu ý: Đây là bản mẫu hoàn chỉnh dựa trên yêu cầu nhìn thấy trong ảnh đề bài. Nếu giảng viên yêu cầu dùng đúng bộ ảnh/nội dung trong mã nguồn GitHub gốc, hãy thay nội dung tương ứng trước khi nộp.
